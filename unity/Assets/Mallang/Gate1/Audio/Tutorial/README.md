# 말랑브레인음악대 · 기본 타격음 v1

## 포함 파일

- **둥:** `dung_01.wav`(추천/균형형), `dung_02.wav`(짧고 탄력 있음), `dung_03.wav`(몸통음이 조금 길고 도톰함)
- **탁:** `tak_01.wav`(추천/균형형), `tak_02.wav`(조금 더 선명함), `tak_03.wav`(조금 더 부드러움)
- **비교 듣기:** `compare_all_3_pairs.wav` — 01 둥→01 탁 / 02 둥→02 탁 / 03 둥→03 탁 순서. 무음 간격만 추가했으며 개별 WAV는 변경하지 않음.

## 기술 사양

모든 파일은 **48,000 Hz · 모노 · 24비트 PCM WAV**입니다. 앞무음 없이 곧바로 발음하며, 끝에 짧은 부드러운 페이드아웃을 적용했습니다. 인위적으로 길게 늘어지는 잔향은 없습니다. 모바일 스피커를 고려해 둥의 저역에 **중역 배음**을 포함했습니다. 실제 기기에서 최종 음량 밸런스와 레이턴시를 반드시 다시 검증하세요.

## 사용·출처 기록

- **원천:** 외부 샘플 또는 제3자 음악 파일을 사용하지 않고, 난수 노이즈·진동 모드·감쇠 필터를 조합해 프로젝트용으로 새롭게 **절차적 합성**함.
- **제3자 출처:** 없음.
- **조건:** OpenAI 서비스를 통해 생성한 산출물로, 실제 사용 권한은 해당 서비스의 이용 약관에 따름. 별도 구매한 음원/외부 샘플의 라이선스 조건은 포함되어 있지 않음.
- **Unity 원칙:** 튜토리얼 예시와 사용자의 실시간 입력 타격음에서 **같은 WAV를 재사용**할 것. 저지연 오디오 경로 및 DSP 타이밍은 별도로 검증할 것.

## 추천 첫 비교

`dung_01.wav` + `tak_01.wav`로 시작하고, 음색을 비교할 때 각 쌍의 레벨을 장비에서 다시 확인합니다. `tak_02`가 일부 스마트폰에서 날카로울 수 있으므로 사용성 테스트에 포함해 평가하세요.
