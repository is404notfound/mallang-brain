# 공통 스타일 프롬프트 (고정 · LOCKED, 2026-11-08)

말랑브레인음악대의 **확정 공통 스타일 프롬프트**입니다. 토끼(AST-001)가 승인 캔버스에 수렴한 세션에서 확정되었고, 이걸 **모든 캐릭터 에셋 생성의 접두사로 그대로(verbatim) 재사용**합니다. 함께 **스타일 견본 이미지**를 첨부합니다.

## 쓰는 법 (필수)

1. 아래 **[공통 스타일 — 고정]** 문단을 각 캐릭터 프롬프트 **앞에 그대로** 붙입니다.
2. **스타일 견본 이미지** `art-direction/references/style-exemplar-rabbit.png`(확정 토끼)를 함께 첨부합니다 — "이 견본과 똑같은 선 두께·눈 크기·몸 실루엣·질감으로". ChatGPT 이미지 생성은 **한 세션 맥락 + 견본 이미지**로 수렴하므로, 가능하면 **한 세션에서 이어서** 생성합니다(fresh 병렬은 드리프트).
3. 캐릭터별 묘사(몸 색·악기·성격 순간)는 이 문단 뒤에 붙입니다.

## [공통 스타일 — 고정]

```
말랑말랑한 2D 동물 캐릭터 일러스트. 따뜻한 짙은 먹색(청록빛 도는, 순검정 아님)의 필압 외곽선(가늘→굵→가늘, 매끈한 공장 스티커 선 금지). 머리:몸 비율 1:1 이상. 몸은 하나의 둥글고 통통한 덩어리지만 실루엣은 또렷하게 — 바닥만 살짝 평평하게 앉은 둥근 몸(흐물흐물 녹은 덩어리 금지), 귀·팔은 몸 외곽선과 겹치지 않게 분리, 짧고 뭉툭한 팔다리(손가락·관절 없음). 얼굴: 크고 동그란 검은 점눈 + 눈 안 흰 하이라이트 1개, 작은 w(ω) 모양 입, 코랄 볼 홍조 3선, 눈썹 기본 없음. 소품(나비넥타이·목스카프)은 턱 바로 아래 '목' 위치. 전원 검은 학사모+노란 술. 글로시하고 부드러운 음영, 말랑한 질감. 저녁(황혼) 축제의 따뜻한 전구 빛 톤. 캐릭터 1마리만, 화면 중앙, 투명 배경 PNG, 1:1 정사각 1024px 이상. 특정 IP(치이카와·태고의달인 등)의 얼굴·몸·포즈를 식별 가능하게 모사 금지. 첨부한 style-exemplar-rabbit.png(확정 토끼)와 똑같은 선 두께·눈 크기·몸 실루엣·질감으로 그려줘.
```

## 재사용 (다른 프로젝트/스킬)

- 이 파일은 asset-prompts 스킬이 만드는 **스타일 카드의 1절(공통 스타일)과 짝**을 이룹니다. 새 프로젝트에선 그 프로젝트의 확정 캐릭터 하나가 수렴하면, 같은 방식으로 **공통 스타일 프롬프트 + 스타일 견본 이미지**를 고정해 재사용합니다.
- 고정 후 바뀌면 안 됩니다(필수). 스타일이 바뀌면 견본·프롬프트를 새로 확정하고 버전을 올립니다.
