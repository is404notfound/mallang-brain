# 에셋 제작 워크플로 (그림 한 장이 게임 에셋이 되기까지)

## 개요

회사 가이드(2026-11-17, "1인 1게임 AI 제작" 과제)의 5단계 실무 워크플로를 말랑브레인음악대 공정에 맞게 고정한 문서입니다. 미감 기준은 `style-card.md`(스타일 카드)가 맡고, 이 문서는 **공정 순서와 도구, 증거 보관 규칙**을 맡습니다.

## 사용법

캐릭터·소품 에셋 1종을 만들 때마다 아래 1~5단계를 순서대로 진행합니다. 각 단계의 산출물은 지정된 폴더에 남깁니다.

## 기본 원칙

- **스타일 카드가 모든 생성의 기준입니다** (필수). 프롬프트·인페인팅·3D 변환 어느 단계에서도 카드의 형태 언어·색 위계·금지사항을 우선합니다.
- **탐색은 변수 1개씩 바꿉니다** (필수). 같은 프롬프트로 100장을 뽑지 말고, 색감·재질·형태 중 하나만 바꿔 4장 단위로 비교합니다.
- **중간 산출물은 버리지 않습니다** (필수). 탈락 변형·보정 전후·3면 시트를 `lookdev/`(또는 `asset-requests/_inbox/`)에 보관합니다. 월말 성과 정리의 증거가 됩니다.
- **원화용 고해상도와 Unity 탑재용 최적화본을 구분합니다.** 100px로 표시될 아이콘에 2048px 텍스처를 넣지 않습니다.
- **LoRA·ComfyUI는 지금 도입하지 않습니다.** 대표 캐릭터와 화풍이 확정되고 반복 제작 물량이 생기는 M4 이후에 검토합니다(게이트① 결과 참고).
- **전체 화면 완성컷 생성은 금지입니다** (필수). 생성 이미지는 조각(캐릭터·소품)과 무드보드(분위기 참고)만 허용합니다(2026-11-16 결정).

## 실행 절차

### 1단계: 콘셉트 원화 생성

- 모델 2종만 비교합니다: Krea 2 계열(스타일라이즈드 미감 탐색), Nano Banana 계열(기존 그림 참고 수정·편집). 기존 2D 확정 렌더(`charactors.png`, AST 캐릭터 낱장)를 image→image 레퍼런스로 첨부합니다.
- 일괄 4장 생성 → 실루엣 기준으로 1장 선택 → 그 이미지 기준으로 변형 반복(탐색→선택→개선).
- 산출물: 선택본 1장 + 탈락 변형(`-alt1`, `-alt2`) 보관.

### 2단계: 원화 수정과 일관성 확보

- 인페인팅(일부만 다시 생성)으로 얼굴은 보존하고 귀·의상·악기·손 오류만 고칩니다. 전체 재생성으로 마음에 든 부분을 잃지 않습니다.
- 캐릭터 시트(`charactors.png`)와 비율·화풍을 대조합니다. 볼선 3개·학사모·포인트색 등 식별 요소 점검.
- 산출물: 보정 전/후 쌍 보관.

### 3단계: 제작용 이미지 준비

- 배경 제거로 투명 PNG를 만듭니다. 외곽 흰 테두리·그림자 잘림을 확인합니다.
- 정면·측면·후면 3면(필요 시 ¾)을 확보합니다 — 다음 단계의 3D 변환 입력입니다. 측·후면은 Nano Banana 계열의 참조 편집으로 정면과 일관되게 만듭니다.
- 업스케일은 인쇄·확대 용도에만 씁니다. 없는 디테일을 만들어 단순한 귀여움을 해치면 쓰지 않습니다.
- 산출물: 3면 시트 1장(`lookdev/m1-character.png` 자리).

### 4단계: 게임 에셋으로 변환 (3D)

- 3면 이미지를 Tripo에 넣어 메시를 생성하고, 리토폴로지·UV·텍스처를 정리합니다. AI가 정면 외 형태를 잘못 추정하지 않았는지 3면 원화와 대조합니다 (필수).
- 리깅·스키닝은 Tripo 초벌 + Blender 보정. 클립 4개(Idle 호흡·연주·리액션·기쁨)를 만듭니다.
- 셰이딩은 스타일 카드 0.5절(무광 매트 툰 2~3단, 얇은 다크브라운 외곽선)을 따릅니다.
- 산출물: 메시·텍스처·리그 파일 + 단계별 소요 시간 기록(게이트① 입력).

### 5단계: Unity 적용과 검증

- URP 툰 머티리얼로 씬에 배치하고, 실제 게임 화면에서 크기·연출·성능을 확인합니다.
- 룩 스코어카드(plan.html 3절)로 재채점하고, 실기기에서 확인합니다.
- Unity 탑재본은 해상도·압축을 최적화해 원화와 분리 보관합니다.
- 산출물: 게임 내 캡처 + 10초 영상(월말 증거).

## 주의사항

- AI 배경 제거·3D 변환 결과는 항상 사람 눈 검수를 거칩니다. "됐다"는 도구 로그가 아니라 화면으로 판정합니다.
- 아웃페인팅은 배경 콘셉트·비율 확장용이며, 3D 공간을 만들어 주지 않습니다.

## 용어 설명

- **인페인팅(inpainting)**: 이미지의 지정한 영역만 다시 생성하는 부분 수정 기능입니다.
- **LoRA**: 특정 캐릭터·화풍을 모델에 추가 학습시켜 일관된 그림을 반복 생성하는 기법입니다.
- **리토폴로지(retopology)**: 생성된 3D 메시의 면 구성을 깔끔하게 재정리하는 작업입니다.
- **스키닝(skinning)**: 메시가 뼈대(리그)의 움직임에 어떻게 따라 변형될지 정의하는 작업입니다.
