# 스타일 카드 템플릿

1단계 산출물 `art-direction/style-card.md`의 양식입니다. 아래 7개 섹션을 모두 채웁니다. 각 규칙 끝에 출처 파일명을 답니다(예: `(디자인.md 14절)`). 문서에서 못 찾은 항목은 "문서에서 못 찾음", 문서 근거 없이 메운 것은 "추정:"으로 표시합니다.

---

## 1. 공통 스타일 (모든 프롬프트 접두사)

모든 에셋 프롬프트 앞에 붙일 한 문단. 렌더링 스타일·외곽선·비율·질감·전체 분위기를 한 번에 묘사합니다. 특정 IP를 식별 가능하게 모사하지 않는다는 금지도 여기 포함합니다.

## 2. 색 팔레트

두 칸으로 나눕니다.
- **정성 규칙** (확정): 색의 역할("배경 앵커 = 옅은 한색", "캐릭터 = 따뜻한 난색", 배경:전경 비율 등). 출처 포함.
- **미승인 HEX 후보** (참고): 문서에 있으나 승인되지 않은 수치. "미승인"으로 명시하고 정성 규칙과 섞지 않습니다.

## 3. 구도·위계 규칙

- 겹 구조(배경/중경/전경/공기)와 깊이 단서.
- 명도·채도 위계(배경이 캐릭터보다 한 단계 물러남)와 여백.
- "한 장면·한 감정" 초점 구성.
- 화면별 가독 시선 순위(있으면).
- 각 규칙에 출처.

## 4. 캐릭터 시트

캐릭터별로 외형·성격·대표 소품(악기 등)·포인트색·시그니처 순간·공통 규칙. 표 형식 권장. 출처 포함.

## 5. 재질 언어

요소 종류별 질감 규칙(예: 누르는 것 / 읽는 것 / 버튼). 각 질감의 하지 말 것(과한 사실적 손상 등) 포함. 출처.

## 6. 금지사항

하지 말아야 할 시각 표현을 목록으로. IP 모사, 특정 얼굴 기호, 유아용 문법, 숨긴 정답 노출, 기획 표기 노출 등. 각 항목 출처.

## 7. 레퍼런스 이미지 매핑

어떤 승인 이미지·스토리보드 컷을 어떤 에셋(또는 에셋 종류)의 image→image 스타일 레퍼런스로 붙일지. 파일 경로와 용도. 레퍼런스가 없으면 "없음"으로 표시.
