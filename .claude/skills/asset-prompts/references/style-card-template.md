# 스타일 카드 템플릿

1단계 산출물 `art-direction/style-card.md`의 양식입니다. 아래 7개 섹션을 모두 채웁니다. 각 규칙 끝에 출처 파일명을 답니다(예: `(디자인.md 14절)`). 문서에서 못 찾은 항목은 "문서에서 못 찾음", 문서 근거 없이 메운 것은 "추정:"으로 표시합니다.

---

## 0. 기준 시각 — 확정 이미지 (최우선)

확정된 스토리보드·시안 이미지가 있으면 **여기에 파일 경로와 관측 사실을 적고, 이 이미지를 미감의 1차 기준으로 삼습니다.** 캐릭터·`scene-with-subject`·타이틀 에셋은 이 이미지를 image→image 레퍼런스로 첨부합니다. 관측(레터링·버튼·캐릭터 외형·배경 구성·실제 색)을 구체적으로 적고, 글 규칙과 어긋나는 점은 "확인 필요"로 표시합니다. 확정 이미지가 없으면 "없음(렌더 이미지 미보관)"이라고 적습니다.

## 1. 공통 스타일 (모든 프롬프트 접두사)

모든 에셋 프롬프트 앞에 붙일 한 문단. 렌더링 스타일·외곽선·비율·질감·전체 분위기를 한 번에 묘사합니다. 특정 IP를 식별 가능하게 모사하지 않는다는 금지도 여기 포함합니다.

## 1.5 감성 레버 (이 게임의 핵심 차별점 — 최우선 의도)

이 게임의 차별점이 "미감·상호작용으로 감성을 자극"하는 것이면, 모든 에셋이 **정확함을 넘어 감정을 품도록** 만듭니다. 디자인 문서의 "감성 포인트/차별점" 서술을 여기 옮기고, 이미지 차원의 레버로 번역합니다.

- **목표 감정 팔레트**: 이 게임이 주려는 느낌 몇 개(예: 따뜻함·설렘·귀여움·평화로움·뿌듯함). 출처.
- **이미지 레버**(정적 이미지가 감정을 품게 하는 수단):
  - 빛: 따뜻한 글로우·림 라이트·빛 웅덩이로 포근함.
  - 표정·몸짓: 다정한 미소·반짝 눈·홍조, "포즈가 아닌 한 순간"(서로 귀 기울임·수줍은 빼꼼·기뻐하는 찰나).
  - 질감: 말랑·둥근 덩어리·부드러운 하이라이트로 만지고 싶은 느낌.
  - 공기감: 반짝임·꽃잎·빛 입자 소량으로 살아있는 분위기.
- **감성 포인트 목록**: 문서에 있는 구체 포인트(예: 라운드 클리어 때 전구가 퐁, 결과의 빛 모임, 벚꽃 흩날림)를 적되, **상호작용/애니메이션 차원은 장면 레인 몫**이라 표시하고, 정적 이미지가 그 순간의 감정을 미리 품도록 번역합니다.

## 2. 색 팔레트

두 칸으로 나눕니다.
- **정성 규칙** (확정): 색의 역할("배경 앵커 = 옅은 한색", "캐릭터 = 따뜻한 난색", 배경:전경 비율 등). 출처 포함.
- **미승인 HEX 후보** (참고): 문서에 있으나 승인되지 않은 수치. "미승인"으로 명시하고 정성 규칙과 섞지 않습니다.

## 3. 구도·위계 규칙

- 겹 구조(배경/중경/전경/공기)와 깊이 단서.
- 명도·채도 위계(배경이 캐릭터보다 한 단계 물러남)와 여백.
- "한 장면·한 감정" 초점 구성.
- 화면별 가독 시선 순위(있으면).
- 각 규칙에 출처.

## 4. 캐릭터 시트

캐릭터별로 외형·성격·대표 소품(악기 등)·포인트색·시그니처 순간·공통 규칙. 표 형식 권장. 출처 포함.

## 5. 재질 언어

요소 종류별 질감 규칙(예: 누르는 것 / 읽는 것 / 버튼). 각 질감의 하지 말 것(과한 사실적 손상 등) 포함. 출처.

## 6. 금지사항

하지 말아야 할 시각 표현을 목록으로. IP 모사, 특정 얼굴 기호, 유아용 문법, 숨긴 정답 노출, 기획 표기 노출 등. 각 항목 출처.

## 7. 레퍼런스 이미지 매핑

어떤 승인 이미지·스토리보드 컷을 어떤 에셋(또는 에셋 종류)의 image→image 스타일 레퍼런스로 붙일지. 파일 경로와 용도. 레퍼런스가 없으면 "없음"으로 표시.
