# 말랑두뇌음악대학

가로 화면에서 마림바를 연주하는 1인 개발 캐주얼 리듬게임이다. 브레인 콘테스트의 재도전 재미와 음악대학에서 성장하는 느낌을 만든다. 현실의 지능 향상이나 치료 효과를 주장하지 않는다.

## 프로젝트 문서

- [Gate 0 시험 장면 실행 방법](tools/gate0/README.md): Android·WebGL 빌드, Toss 패키징, 자동 테스트. 기술 시험용이며 게임 완성판이 아니다.

- [전체 문서 안내](docs/README.md): 제품 방향, 기술 시험, 개발 순서, 화면 설계.
- [연습실·콘테스트·뇌 타워 밸런스 설계](docs/01-product/practice-contest-balance-design.md): 두 연습 방식, 뇌 성향, 스테이지 난이도와 타워 분포.
- [수익화·퍼블리싱 전략](docs/01-product/monetization-and-publishing-strategy.md): 국내·글로벌 채널, 무료+광고 모델, 두 언어 대응, 사업 위험.
- [구현 전 체크리스트](docs/03-development/pre-implementation-checklist.md): 단계별 준비 문서와 아직 결정할 일.
- [할 일](TODOS.md): 기술 시험 이후 작업과 공개 준비.

문서에 적힌 계획과 실제 구현·시험 완료는 다르다. 현재 기술 시험의 기준은 [Gate 0 구현 계획](docs/02-gate-0/implementation-plan.md)을 따른다.
