# 말랑브레인음악대학

마림바 리듬과 100인 브레인 콘테스트를 결합한 가로형 캐주얼 게임입니다.

## 현재 단계

콘텐츠와 백엔드 구현에 앞서 Gate 0 기술 스파이크를 준비하고 있습니다. 하나의 Unity 6 프로젝트가 다음 두 필수 채널에서 같은 리듬 입력·오디오·군중 부하를 감당하는지 먼저 검증합니다.

- Android 네이티브: Google Play 등급·배포 경로를 확보하는 채널
- Apps in Toss Unity WebGL: 실제 수익화를 담당할 핵심 채널

한 채널만 통과한 상태로 Gate 1을 시작하지 않습니다.
