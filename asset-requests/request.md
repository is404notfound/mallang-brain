# RR02 에셋 생성 요청서 (사람용)

## 개요

이 호스트는 이미지 생성을 할 수 없어, 필요한 그림을 스프라이트 시트(여러 그림을 격자로 한 장에 모은 이미지) 3장으로 요청합니다. 생성한 PNG를 이 폴더(`asset-requests/`)에 아래 파일 이름으로 넣고 분리 스크립트를 실행하면, 각 칸이 잘려 코드의 자리(slot)로 들어갑니다. 구현은 placeholder로 끝까지 조립되므로, 에셋이 늦어도 개발은 막히지 않습니다.

## 공통 스타일

- 승인된 스타일 가이드(`docs/04-design/말랑두뇌음악대_스타일가이드.md`)와 2026-11-07 승인 아트 방향(`디자인.md` v2.1)을 따릅니다.
- 투명 배경 PNG, 칸 사이 여백 없음, 각 칸 중앙 정렬 (필수 — 분리 스크립트가 균일 격자로 자릅니다).
- 네 친구 성격: 토끼(장난기), 카피바라(초롱초롱함), 사막여우(까칠하고 삐쭉함), 다람쥐(소심하고 망설임).

## 시트 목록

### SHEET-01 · `characters.png` — 2048×1024 (4열×2행, 칸 512×512)

윗줄 왼→오: 토끼 기본 / 카피바라 기본 / 사막여우 기본 / 다람쥐 기본 (각자 악기: 실로폰·큰북·트럼펫·플루트)
아랫줄 왼→오: 같은 순서의 연주 타격 자세. 기본 자세와 같은 크기·발 위치 기준이어야 화면에서 바꿔 끼울 때 튀지 않습니다.

### SHEET-02 · `brain.png` — 1024×256 (4열×1행, 칸 256×256)

왼→오: 콩알 뇌(아주 작음) → 자란 뇌 → 점화된 뇌(은은한 반짝임) → 치솟는 뇌(강한 발광). 같은 뇌가 자라는 연속감이 있어야 합니다.

### SHEET-03 · `background.png` — 1280×720 (1칸)

음악대 무대 배경. 화면 중앙 48% 폭에 악보가 올라가므로 그 영역은 차분하고 대비가 낮게, 좌우 26%씩은 캐릭터 카드가 덮습니다.

## 받은 뒤 실행할 명령

```
python3 /Users/easyoon/.claude/plugins/cache/plan-handoff-local/plan-handoff/0.11.0/scripts/split_spritesheet.py asset-requests/manifest.json
```

- 캐릭터 칸이 격자에 안 맞게 그려졌으면 `--sheet SHEET-01 --mode bbox`로 윤곽 기준 분리를 쓰세요.
- 이미 placeholder가 자리에 있으면 `--force`로 덮어씁니다. 결과는 `asset-requests/placed.json`에 기록됩니다.

## 소리 에셋 (별도 — 시트 아님)

FR-019의 정체성 음 4종은 그림이 아니라 소리 후보 선정 문제입니다. 악기/목소리/혼합 후보를 150BPM·8음 연속·20회 반복 기준으로 비교 청취해야 하며(패키지 `sound-direction.md`의 선정표), 이 선정은 사람 청취 플레이테스트 몫입니다. 프로토타입은 구별되는 placeholder 톤 4개(코드 생성)로 조립하고, 후보 음원이 오면 같은 slot(`unity/Assets/Mallang/RR02/Audio/voice-<friend>.wav`)에 끼웁니다.
