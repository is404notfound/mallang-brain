# RR02 에셋 생성 프롬프트 (GPT용 · 복붙 편의판)

스타일 카드 `art-direction/style-card.md`(승인 v3)와 승인 캔버스로 만든 에셋별 프롬프트입니다. **각 블록이 자체 완결**이라, 블록 하나를 통째로 복사해 GPT에 붙이고 지정 이미지를 첨부하면 됩니다.

## 가장 효율적이고 고퀄로 뽑는 법 (읽고 시작하세요)

- **한 번에 다 붙여넣기는 비추천입니다.** ChatGPT 이미지 생성은 **한 메시지에 그림 한 장**을 만듭니다. 13개를 한꺼번에 붙이면 13장이 따로 안 나오고 한 장에 뭉치거나 품질이 떨어집니다. → **에셋당 블록 하나씩** 보내세요.
- **각 블록에 "첨부" 이미지를 꼭 같이 올리세요.** ChatGPT는 파일 경로를 스스로 못 읽습니다(자동 참조 불가). 그 이미지를 **드래그해서 첨부**해야 스타일이 일관되게 나옵니다(image→image).
- **순서 추천**: ① 캐릭터 기본 4개(AST-001~004)를 먼저 뽑아 네 친구 얼굴을 확정 → ② 타격 4개(005~008) → ③ 뇌 4단계(009~012) → ④ 배경(013). 앞에서 확정된 캐릭터 그림을 뒤 생성의 참고로 다시 첨부하면 더 일관됩니다.
- **투명 배경이 필요한 것**(캐릭터·뇌)은 블록에 이미 "투명 배경"이 들어 있습니다. ChatGPT가 투명을 잘 못 하면, 단색 배경으로 받아 나중에 배경만 지워도 됩니다.
- **변형**: 캐릭터는 "3안"을 요청하게 써 뒀습니다. 마음에 드는 1장을 고르세요. 뇌·배경은 1장.
- **저장**: 받은 그림을 `asset-requests/_inbox/`에 **지정 파일명**으로 저장 → 아래 "배치" 실행.

> 색은 정확한 HEX가 없어 정성적으로 적었습니다. **정확한 톤은 첨부 이미지에서 가져가라**고 프롬프트에 넣었습니다. GPT가 영어를 선호하면 블록을 영어로 옮겨도 되지만, **이미지 첨부가 품질에 가장 큽니다.**

## 배치 (그림을 다 받은 뒤)

받은 PNG를 `asset-requests/_inbox/`에 위 저장명대로 넣고:
```
python3 .claude/skills/asset-prompts/scripts/place_by_name.py asset-requests/manifest.json
```
- slot에 placeholder가 있으면 `--force`. 결과는 `placed.json`.
- 3안을 다 저장하려면 `-v1`~`-v3`로 저장하고 `manifest.json`의 `chosen`에 고른 파일명을 적으세요.
