# 전달 자산 연결과 악보 탭 흔적 — 2026-10-11

## 적용

- 사용자 디자인 문서를 저장소 루트 `DESIGN.md`에 원문 그대로 저장했다. 아트 가이드로 참고하며, 문서 속 미래 애니메이션·폴더 예시를 별도의 추가 작업 지시로 취급하지 않았다.
- `Assets/Mallang/Gate1/Art/Tutorial/`에 종이 배경, 북, 나무 타격판 원본 PNG를 저장했다.
- 원본 PNG의 투명 여백과 픽셀은 변경하지 않았다. 악기의 화면 표시 영역만 UV(이미지에서 그릴 부분의 좌표)로 잘라 실제 그림을 크게 보여준다.
- 화면의 추가 그림자를 제거하고 디자인 문서 팔레트에 맞췄다.
- `Assets/Mallang/Gate1/Audio/Tutorial/`에 ZIP의 파일 9개를 저장했다. 원본 설명서, 출처 기록, 비교 음원과 나머지 후보도 보관했다.
- 튜토리얼 장면에 이미지 3개와 추천 소리 `dung_01.wav`, `tak_01.wav`를 직접 연결했다.
- 예시와 실제 입력은 각 손에 같은 AudioClip을 사용한다. 무음 보정·임의의 시간 보정은 추가하지 않았다.
- 짧은 타격 WAV의 가져오기 설정은 미리 로딩, PCM, 원본 샘플레이트 유지로 지정했다. 이미지에는 밉맵을 사용하지 않는다. 기존 IMGUI와 호환되도록 Texture2D로 가져온다.
- 기존 토끼 몸과 뇌의 분리 표시를 유지한다. 새 캐릭터 프레임을 만들지는 않았다.

## 탭 흔적

- PlayerPerformance에서 새로운 누름 입력마다 흔적을 생성한다. 놓기·중복 누름에는 만들지 않는다.
- 입력 이벤트 시각을 기존 시계 변환으로 DSP(오디오 시계) 시각에 맞춘 뒤, 패턴 길이에 따른 악보의 가로 위치에 기록한다.
- 정답 음표 위치로 흔적을 옮기지 않는다. 늦게 누르면 음표 오른쪽, 빠르게 누르면 왼쪽에 표시된다.
- 사용자 판정 보정값은 빛의 위치에 적용하지 않는다. 실제 입력 위치와 정답 판정은 구분한다.
- 윗줄은 왼손의 따뜻한 금빛, 아랫줄은 오른손의 분홍빛이다. 동시에 입력하면 각각 흔적이 생긴다.
- 작은 중심점, 부드러운 빛, 퍼지는 고리를 0.55초 동안 표시한다. 고리는 반경 6→25 기준 단위로 커지며 투명해진다.
- 악보 안으로 표시를 제한한다. 화면 흔들림, 시간 정지, 입력 지연은 추가하지 않는다.
- 최대 흔적 64개를 보관한다. 오래된 흔적은 지우며, 패턴 전환·재시작·화면 비활성화 때 초기화한다.
- 판정과 채점 코어, 콘테스트 코드는 이번 작업에서 변경하지 않았다.

## 검증 결과

### 확인함

- 원본 PNG 3개와 프로젝트 복사본의 SHA-256 일치.
- 사용자 `design.md`와 저장소 `DESIGN.md`의 파일 내용 완전 일치.
- ZIP 내부 파일 9개와 프로젝트 복사본의 내용 완전 일치.
- 튜토리얼 장면의 연결 7개(토끼, 글꼴, 새 이미지 3개, 소리 2개)가 각각 실제 파일과 유일한 GUID를 가리키는지 재확인했다.
- 추천 WAV는 둘 다 48kHz·모노·24bit. 둥 0.255초, 탁 0.155초.
- Unity 6000.3.23f1에 포함된 C# 컴파일러와 프로젝트 기존 컴파일 설정으로 Runtime, EditMode 시험 코드, PlayMode 시험 코드를 컴파일했다. 모두 오류 0, 종료 코드 0. 출력은 임시 폴더에 저장했다.
- `git diff --check` 통과.

### 추가한 시험, 실행은 아직 미완료

- `TutorialArtworkSceneTests`: 실제 장면의 토끼·글꼴·새 이미지 3개·소리 2개 연결.
- `TutorialTapTraceTests`: 준비/예시/카운트다운에는 흔적 없음, 양손 동시 흔적, 정답이나 판정 보정값과 독립된 입력 위치, 중복 포인터 제외, 패턴 초기화.

### 미확인

- Unity 시험 실행기는 원본 프로젝트가 이미 다른 Unity 인스턴스에서 열려 있어 종료 코드 1로 중단됐다. 컴파일 성공을 시험 통과로 취급하지 않는다.
- Unity의 실제 이미지 가져오기와 장면 표시, 빛의 시각적 강도, 소리 청취, 전체 흐름과 재연주는 이번 변경 후 직접 확인하지 못했다.
- 모바일 입력 지연·오디오 정확도는 측정하지 않았다. Gate 기준이나 측정 제한은 변경하지 않는다.

## 사용자가 확인할 위치

Unity에서 재생을 정지하고 파일 가져오기/컴파일을 기다린 뒤 `Assets/Mallang/Gate1/Scenes/ListenRepeatTutorial.unity`를 열고 Play한다. A/F는 왼손, J/L은 오른손이다. 연주 단계에서 누르면 해당 악보 줄의 실제 탭 위치에 빛이 퍼진다.

Test Runner에서 EditMode의 `TutorialArtworkSceneTests`, PlayMode의 `TutorialTapTraceTests` 및 기존 시험을 실행할 수 있다.
