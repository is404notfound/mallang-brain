# 시작 휴식·10개 리듬·세트 콤보 — 2026-10-12

## 적용한 동작

- 기존 준비 신호 뒤의 다음 박자를 비우고 그 다음 박자에 연주를 시작한다. 80 BPM에서 기존 시작보다 0.75초 늦다. 마지막 신호 시작부터 연주 시작까지는 1.5초다. 기존 신호음 길이가 약 0.17초이므로 신호 종료 후에도 한 박자 이상의 준비 시간이 남는다.
- 쉬는 박자에는 ‘한 박자 쉬고…’를 표시한다. 입력 판정은 PlayerPerformance 전까지 비활성이다. 예시·악보·입력의 오디오 시계는 기존 방식을 유지한다.
- ‘위: 왼손 둥 / 아래: 오른손 탁’ 문구를 제거했다.
- 양쪽 입력 영역을 누르면 화면 가장자리에서 중앙 방향으로 볼록한 회색 반원이 0.28초 동안 나타나고 옅어진다. 최대 불투명도는 22%다. 각 영역은 안전 영역의 29% 이내이며 악보를 덮지 않는다. 양손 동시 입력은 두 반원을 함께 표시한다.
- 이전에 넣은 실제 탭 위치의 악보 빛 효과는 유지한다.

## 리듬 10개

기존 탭 리듬 LR01~LR06을 재사용했다. 기존 LR07~LR10에는 홀드가 있어 보존하고, 이 튜토리얼에서는 탭 전용 TR07~TR10을 추가했다. 모두 480 ticks/beat, 4/4 한 마디, 80 BPM이다.

| 번호 | ID | 구성 |
|---|---|---|
| 1 | LR01 | 왼손·쉼·오른손·쉼 |
| 2 | LR02 | 정박 좌우 교대 |
| 3 | LR03 | 왼손 두 번·오른손 두 번 |
| 4 | LR04 | 반 박자 간격 왼손 두 번·쉼·오른손 두 번 |
| 5 | LR05 | 반 박자 뒤에서 시작하는 좌우 교대 |
| 6 | LR06 | 전반 두 박자에 빠른 좌우 네 번 |
| 7 | TR07 | 왼손·오른손·오른손·왼손 |
| 8 | TR08 | 좌우 빠르게·쉼·좌우 빠르게·쉼 |
| 9 | TR09 | 반 박자 간격 세 번씩 두 묶음 |
| 10 | TR10 | 반 박자 간격 좌우 교대 여덟 번 |

예시 예약 소리 슬롯을 4개에서 8개로 늘려 마지막 패턴의 뒷부분이 누락되지 않도록 했다. 마지막 결과 뒤에는 다시 연주할 수 있다.

## 세트 콤보와 뇌

- 세트의 기존 점수 기반 정확도가 **70% 이상**이면 성공이다. Perfect 100, Good 70, Miss 0의 기존 채점 기준을 유지한다.
- 성공할 때 세트 콤보 +1, 뇌 크기 +0.05. 70% 미만이면 세트 콤보 0, 뇌 크기 -0.05.
- 시작 크기 0.40, 최소 0.35, 최대 0.90. 10개 연속 성공하면 최대 크기에 도달한다. 콤보가 끊겨도 누적 크기를 전부 초기화하지 않고 조금만 줄인다.
- 원본 뇌 그림의 기준 너비 82에 최대 배율 0.90을 적용한다. 기준 화면에서 최대 너비는 73.8이며 토끼 전체 너비 232보다 작다. 기존 머리 안 배치를 유지하고 성장의 초과 확대 효과를 제거했다. 실제 원화의 머리 경계 안에 들어가는지는 Unity 화면에서 추가 확인이 필요하다.
- 세트 전환은 콤보와 누적 크기를 유지한다. 재연주는 초기 크기와 콤보 0으로 시작한다.

## 첫 탭 시작 대안 검토

고정 시작에 한 박자 휴식을 추가하는 방법을 이번에 적용했다. 예시를 듣고 준비 박자의 템포를 이어갈 수 있고, 첫 음이 없는 LR05도 같은 규칙으로 플레이한다.

첫 탭 시작은 사용자가 충분히 기다릴 수 있다는 장점이 있다. 그러나 LR05처럼 첫 박자에 음이 없는 리듬에서는 첫 탭을 패턴 시작으로 볼지 첫 음의 위치로 볼지 모호하다. 시작 탭을 별도로 받으면 시작 입력과 연주 입력을 구분하는 안내가 필요하다. 첫 탭을 무조건 정답 처리하면 정확도 기준도 달라진다. 이번 변경에는 넣지 않았다.
