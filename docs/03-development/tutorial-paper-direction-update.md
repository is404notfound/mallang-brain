# 튜토리얼 A 방향 임시 적용 — 2026-10-11

## 적용한 변경

- 기존 IMGUI 화면을 유지하고 A ‘종이 위 작은 음악대’ 스타일을 적용했다.
- 배경은 아이보리색의 약한 종이 결이다. 외부 그림이 없을 때 코드로 만든 임시 배경을 사용한다.
- 큰 ‘둥/탁’ 글자 패드를 임시 북과 나무 타격판으로 바꿨다. 터치 영역과 좌우 입력 구분은 유지한다.
- 예시 타격 시 해당 악기도 반응한다. 판정 시간과 그림의 반응 시간은 분리한다.
- 첫 패턴 안내에는 악기와 손의 이름을 짧게 보여준다. 키보드 안내는 에디터에서만 보인다.
- 악보의 두 손은 행, 색, 모양으로 구별한다. 기존 패턴 시각을 그대로 사용한다.
- 글자색과 다시 연주 버튼의 배경을 명시적으로 지정했다. 기본 GUI 스킨의 흐릿한 색과 회색 버튼을 제거했다.
- 제공한 토끼 몸과 뇌를 원본 이미지에서 각각 표시하는 연결을 유지했다.
- 이미지 가져오기 설정을 Texture2D, 최대 2048px, 알파 투명도, 밉맵 없음으로 명시했다. GUID는 바꾸지 않았다.
- 원본을 못 읽으면 기본 도형 토끼로 조용히 대체하지 않는다. 화면 안내와 오류 로그를 남긴다.
- 실제 장면의 토끼 참조, Resources 로딩, 이미지 크기, 한글 글꼴 참조를 확인하는 시험을 추가했다.
- 임시 ‘탁’ 합성음을 짧은 나무 타격 형태로 조정했다. ‘둥’의 음높이 변화는 누적 위상으로 계산한다.
- 예시와 입력은 같은 소리, 같은 소스 음량 0.55, 중앙 배치를 사용한다.

이 합성음은 실제 녹음 샘플이 아니다. 더 좋은 음질이라고 청취 검증한 것은 아니다.

## 새 자산을 받으면 교체할 곳

`ListenRepeatTutorial` 장면의 `ListenRepeatTutorialScreen` 컴포넌트에서 다음 항목을 연결한다.

| 항목 | 연결할 파일 | 비워 두면 |
|---|---|---|
| Paper Background | 종이 배경 이미지 | 임시 종이 배경 |
| Left Instrument | 낮은 북 투명 이미지 | 임시 북 도형 |
| Right Instrument | 나무 타격판 투명 이미지 | 임시 나무 타격판 도형 |
| Dong Sample | 낮은 북 AudioClip | 임시 합성 둥 |
| Tak Sample | 높은 타격 AudioClip | 임시 합성 탁 |

Rabbit Atlas에는 제공한 원본을 계속 연결한다. 뇌의 크기와 성공 기준은 그림 교체와 관계없이 기존 Flow에서 관리한다. 외부 소리 파일은 런타임 종료 때 삭제하지 않는다.

## 검증한 것

- Unity 6000.3.23f1에 포함된 C# 컴파일러와 기존 프로젝트의 컴파일 설정을 사용해 Gate1 Runtime 코드 전체를 컴파일했다. 오류 0, 종료 코드 0.
- 새 장면 자산 시험을 포함해 Gate1 EditMode 시험 코드를 컴파일했다. 오류 0, 종료 코드 0.
- 컴파일 출력은 임시 폴더에 저장했다. 열린 프로젝트의 라이브러리 DLL은 덮어쓰지 않았다.
- `git diff --check` 통과.

## 아직 확인하지 못한 것

- Unity EditMode/PlayMode 시험은 이번 변경 후 실행 완료하지 못했다. 코드 컴파일은 시험 통과와 다르다.
- 열린 Unity 창을 읽는 자동화가 시간 초과됐다.
- 별도 시험 실행은 원본 프로젝트가 열려 있어 거부됐다. 임시 복사본의 일반 실행도 라이선스 연결에 실패했다.
- 로그에 있는 라이선스 연결 값을 재사용하는 방식은 자동 승인 검토가 인증 연결 정보 재사용 위험으로 거부했다. 그 방식은 중단했다.
- 사용자 스크린샷에서 원본 대신 대체 토끼가 나온 정확한 실행 원인은 여전히 미확정이다. 새 가져오기 설정과 시험은 재발을 확인하기 위한 조치이며, 실제 원본 표시를 확인한 결과가 아니다.
- 실제 Unity 화면의 대비, 여러 화면 비율, 전체 재연주 흐름, 새 임시 소리 청취, 모바일 지연 측정은 미확인이다. Gate 0 통과로 처리하지 않는다.

## Unity에서 확인하는 순서

1. 재생 중이면 정지한다.
2. 편집기로 돌아가 파일 변경 가져오기와 컴파일을 기다린다.
3. `Assets/Mallang/Gate1/Scenes/ListenRepeatTutorial.unity`를 연다.
4. Play를 눌러 원본 토끼, 종이 배경, 두 악기 표시를 확인한다.
5. A/F는 왼손, J/L은 오른손이다. 두 패턴 후 다시 연주 버튼을 확인한다.
6. Test Runner에서 EditMode의 `TutorialArtworkSceneTests`와 기존 전체 시험을 실행한다.
