# 추측·패키지 밖 입력 기록 (assumptions.md)

## 개요

패키지만으로 알 수 없어 보수적으로 해석한 것(추측)과, 구현 중 사용자가 패키지 밖에서 더한 입력을 기록합니다. 이 기록은 8단계 완료 보고와 다음 기획으로 돌아갑니다.

## 패키지 밖 입력

- **OUT-001 (2026-11-07, 사용자 지시)**: freeze로 잠긴 이 패키지로 프로토타입 구현을 시작하라는 지시. 패키지 내부 quickstart.md의 "독립검토 최종판정/사용자승인 전이므로 잠긴 구현 인계 패키지로 취급하지 않음" 문구와 4차 감사의 "ready가 handoff 승인을 뜻하지 않음" 유보보다 사용자(승인권자)의 직접 지시를 우선합니다.
- **OUT-002 (2026-11-07, 사용자 지시)**: 실행자 비용 계층은 B 방식(전부 로컬 Strata 먼저, 상한 2회 소진 시 Haiku, 그다음 Sonnet/세션). 에셋은 요청서로만 정리(이 호스트는 이미지 생성 불가).
- **OUT-003 (2026-11-07, 사용자 선택)**: 테스트 명령은 전용 러너(`tools/handoff/run-tests.mjs`), 작업 브랜치는 `feature/001-listen-and-repeat-impl`.

## 추측 (보수적 해석)

- **ASM-001 패키지 위치**: 패키지가 구현 워크트리(main)에 없고 `feature/game-planning` 워크트리(`/Users/easyoon/mallang-brain/specs/001-listen-and-repeat-core`)에만 있습니다. 그 경로에서 읽기 전용으로 참조합니다.
- **ASM-002 랭킹 서버**: ranking-contract.md가 "실제 서버는 미구현, 인증·제공자 미정"이라고 공개합니다. 프로토타입은 `IRankingServer` 주입 지점을 두고 계약대로 동작하는 스텁(멱등·검증 상태)을 씁니다. 실서버 연동은 미확인 목록에 남깁니다.
- **ASM-003 FR-026 기술 확인**: 감사가 WebGL 영상/GIF 저장 기술 확인 미수행을 공개했습니다. 공유 동선은 교체 가능한 placeholder로 조립하고(이미지 카드 우선), WebGL 녹화 가능 여부는 미확인 목록에 남깁니다.
- **ASM-004 시계 보정 재사용**: 패키지는 보정 규칙(160표본·5ms·int64 µs)만 정의하고 구현 위치를 지정하지 않습니다. Gate 0A에서 실기기 검증된 `Mallang.Gate0.Runtime` Clock 계열을 참조 재사용하는 것이 가장 보수적이라고 판단했습니다(새로 쓰면 검증을 잃음).
- **ASM-005 네 친구 식별자**: 본문은 여우·토끼·카피바라·다람쥐이고, 패키지 와이어프레임·스토리보드가 fox(100회)·rabbit(43회)·capybara(76회)·squirrel(76회)을 씁니다. 코드 식별자도 같은 영문 넷으로 정합니다(저장 키 `brain:RR02:v1:<friend>`에 들어가므로 패키지 표기와 일치시키는 것이 가장 보수적).
- **ASM-007 에셋 요청서 위치**: 에셋 계약의 기본 위치는 `<패키지>/asset-requests/`이지만 패키지가 봉인되어 있어 구현 저장소 루트(`palolo/asset-requests/`)에 둡니다. slot 경로는 저장소 루트 기준입니다.
- **ASM-006 감사 pending 승계**: 시각 확인 19건 pending, design.assets 비어 있음은 구현이 해소할 수 없는 패키지 상태입니다. 장면 레인 사람 확인과 에셋 요청서(7단계)로 승계합니다.
