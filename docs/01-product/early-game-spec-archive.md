# 초기 게임 기획안 (보관용)

> 이전 이름: 말랑뇌리듬스쿨

## 먼저 읽는 쉬운 설명

이 문서는 처음에 생각한 게임의 큰 설계도다. 플레이어는 리듬에 맞춰 화면을 누르고, 다른 99명과 함께 끝까지 남는 것을 목표로 한다. 게임이 끝나면 순위와 기록을 받고, 재미있는 결과 카드를 다른 사람에게 보여 줄 수 있다.

게임의 핵심은 다음과 같다.

- 박자에 맞춰 누르면 좋은 점수를 받는다.
- 틀리거나 늦으면 탈락할 수 있다.
- 다른 사람과 동시에 하지 않아도, 같은 조건으로 순위를 겨룰 수 있다.
- 귀엽고 우스운 뇌 캐릭터와 효과로 보는 재미를 만든다.
- 첫 버전에서는 꼭 필요한 기능만 만들고, 나머지는 나중에 결정한다.

아래에는 화면 구성, 캐릭터 모습, 기술 선택, 광고와 유료 상품 계획까지 같은 내용을 더 자세히 적어 두었다. 이 문서는 이후의 음악대학 방향을 정리한 제품 비전 문서와 함께 읽으면 좋다.

어려운 말은 [문서 안내](../README.md)에서 먼저 확인할 수 있다.

## 왜 만드는가

Ghost Dash에서 확인한 문제 두 가지:

1. **공유 유인 없음** → 오가닉 유입 0. 바이럴 루프 설계를 처음부터 해야 함.
2. **S0 레버 = 스마트푸시뿐** → 토스 알고리즘 의존. 앱스토어 오가닉 검색 추가 필요.

Ghost Dash 데이터가 준 설계 기준:

- **5판 리텐션 분기점**: 5판 미만 재방문 거의 0% → 첫 5판 설계가 전부
- **D1 복귀 61%**: 데일리 구조가 리텐션 훅으로 직접 작동함
- **초반 이탈 22%**: 첫 관문 난이도 낮게 시작해야 함
- **금요일 피크**: 짧고 자극적인 세션 게임에 적합한 유저층

## 게임 컨셉

귀엽고 하찮은 뇌 캐릭터들이 박자 게임을 진행하는 세계. "두뇌훈련"은 앱 공식 설명이 아닌 마케팅 포지셔닝 용도로만 사용.

**핵심 문장:** "귀엽고 병맛인 뇌들이 박자에 맞춰 탭하는 게임인데, 못해도 귀엽고 잘해도 자랑하고 싶음."

## 게임플레이 스펙

### 입력 메카닉

- **화면 하단**: 좌뇌 탭 존(왼쪽) / 우뇌 탭 존(오른쪽) 2구역
- **탭**: 해당 구역 터치
- **홀드**: 길게 누르기 (길쭉한 바로 표시)
- **난이도 진행**:

| 스테이지 | 입력                  |
| -------- | --------------------- |
| 1~3      | 탭만 (어디든)         |
| 4~7      | 좌/우 구역 구분       |
| 8~12     | 홀드 추가             |
| 13+      | 속도 + 패턴 밀도 상승 |

### 리듬 큐 시스템

- 상단 큐 라인: 한 줄, 색으로 좌/우 구분
  - 좌뇌 탭 = 파란 원 🔵
  - 우뇌 탭 = 빨간 원 🔴
  - 홀드 = 길쭉한 바 (🔵══🔵 또는 🔴══🔴)
- 원들이 왼쪽으로 흘러오고 판정점(║)에서 탭
- 뒤의 큐를 미리 보고 준비하는 구조 (리듬터치 참고)
- 배경에 약한 음악 + 4박자 메트로놈 사운드

### 스테이지 구조

- **정확도 기반 통과**: 매 스테이지마다 정확도(%) 측정 → 기준 이상이면 다음 스테이지
  - 1스테이지: 50% 통과 (Ghost Dash 1.16.0 교훈: 첫 관문 낮게)
  - 5스테이지: 70%
  - 10스테이지: 85%
  - 15스테이지+: 90%+
- **무한 스테이지**: 생존할수록 상위 랭크
- **데일리 리셋**: 매일 자정 랭킹 초기화 → 매일 열어야 하는 이유

## 경쟁 구조

### 비동기 100인 경쟁

- 게임 시작 시 화면에 뇌 캐릭터 100개가 우글우글 꽉 참
- 스테이지 통과 못한 캐릭터들이 우르르 사라짐 (발이 풀리고 쓰러지는 애니메이션)
- 내가 살아남을수록 주변이 비어감 → 상위 x%가 눈으로 직접 보임
- **초기 봇 채우기**: Ghost Dash에서 검증한 방식 동일 적용. DAU 적을 때 봇 100개로 채우고 실유저가 들어오면 봇을 점진적으로 교체

### 랭킹 구조

- 같은 날 플레이한 유저 전체 기준 상위 x% 계산
- 주간 리셋

## 공유 카드 (핵심 바이럴 루프)

Ghost Dash에서 없었던 기능. 이 게임의 가장 중요한 설계.

```
┌─────────────────────────┐
│     말랑뇌리듬스쿨       │
│                         │
│       🧠                │
│   (발이 달린 뇌 캐릭터)  │
│                         │
│   오늘 15스테이지 클리어  │
│     상위 3% 쫄깃뇌!     │
│                         │
│   2026.08.06 랭킹 마감   │
└─────────────────────────┘
```

### 뇌 티어 네이밍

| 상위 % | 티어            |
| ------ | --------------- |
| 1%     | 다이아몬드뇌 💎 |
| 5%     | 단단뇌          |
| 15%    | 탱탱뇌          |
| 40%    | 쫄깃뇌          |
| 70%    | 말랑뇌          |
| 100%   | 흐물뇌          |

- 못해도 귀여운 결과 → 공유 거부감 낮음
- 잘하면 자랑하고 싶음 → 양방향 공유 동기

## UI 레이아웃

**가로(Landscape) 모드** — Ghost Dash와 동일 방향. 뇌 반쪽이 배경을 채우는 컨셉.

```
┌──────────────────────────────────────────────────────┐
│  STAGE 7        ← 🔵🔴🔴🔵║🔵🔴🔵🔴    정확도 83%  │  ← 큐 라인 상단 띠
├─────────────────┬────────────────────┬────────────────┤
│                 │                    │                │
│   좌뇌 배경     │  🧠🧠🧠🧠🧠🧠     │   우뇌 배경    │
│   (병맛 뇌      │  🧠🧠나🧠🧠🧠     │   (병맛 뇌     │
│    반쪽 일러)   │  경쟁자 우글우글    │    반쪽 일러)  │
│                 │  (탈락하면 쓰러짐) │                │
│   [좌뇌 탭 존]  │                    │  [우뇌 탭 존]  │
└─────────────────┴────────────────────┴────────────────┘
```

- 좌/우 배경 = 귀여운 병맛 뇌 반쪽 일러스트 (파스텔 핑크/퍼플)
- 탭할 때 해당 뇌 배경 전체에 신경 전기 이펙트 발생
- 중앙 영역 = 경쟁자 뇌들 우글우글 + 실시간 탈락 연출

## 캐릭터 아트 가이드

- **형태**: 발 달린 동그란 뇌. 위쪽에 주름 2~3개만 (징그럽지 않게)
- **표정**: 점 눈 두 개 + 일자 입. 멍하고 하찮은 기본 표정
- **컬러 팔레트**: 파스텔 (배경 민트, 캐릭터 화이트, 아웃라인 두껍게)
- **레퍼런스**: Kurzgesagt 스타일 심플 캐릭터에 뇌 주름만 추가
- **렌더링**: 100개 동시 렌더링 고려 → 캐릭터 단순하게 유지

### 신경 전기 이펙트 (Unity VFX Graph)

탭/홀드 시 뇌 배경에 전기가 흐르는 시각 피드백. 게임의 핵심 주스(juice).

| 상황            | 이펙트                                                         |
| --------------- | -------------------------------------------------------------- |
| 탭 성공         | 손가락 위치에서 신경섬유 패턴으로 전기가 퍼짐 (노랑/파랑 번개) |
| 홀드 중         | 해당 뇌 전체에 전기가 지글지글 흐름                            |
| 콤보 5단        | 이펙트 색 노랑                                                 |
| 콤보 10단       | 이펙트 색 주황, 강도 상승                                      |
| 콤보 15단+      | 이펙트 색 빨강, 뇌 전체 진동                                   |
| 미스            | 이펙트 없음 + 해당 뇌 배경 살짝 어두워짐                       |
| 스테이지 클리어 | 양쪽 뇌 전체에 전기 폭발                                       |

### 캐릭터 애니메이션

| 상황            | 애니메이션                |
| --------------- | ------------------------- |
| 대기            | 제자리 발 콩콩            |
| 탭 성공         | 발 들고 통통 튐           |
| 홀드 성공       | 발로 버티듯 쪼그려 앉음   |
| 실패            | 발 흐물해지며 주저앉음    |
| 스테이지 탈락   | 발 풀리고 쓰러져서 사라짐 |
| 스테이지 클리어 | 발 들고 방방 뜀           |

## 기술 스펙

### 엔진 & 플랫폼

- **Unity 2D** + Unity MCP (개발 속도 향상)
- **토스 미니앱**: Unity WebGL export → 성능 검증 필요 (Ghost Dash iOS 40fps 문제 반복 가능성)
- **앱스토어/플레이스토어**: 네이티브 빌드 (Capacitor 래핑 또는 직접 빌드)
  - 주의: 단순 웹뷰 래퍼는 애플 가이드라인 4.2 리젝 위험 → 네이티브 기능(햅틱 등) 최소 하나 포함 필요

### 백엔드 (Supabase)

```
테이블:
- daily_scores (user_id, date, stage_reached, accuracy, tier)
- daily_rankings (date, user_id, rank, percentile)

엣지 함수:
- calculate_daily_ranking() → 자정에 실행, percentile 계산
- generate_share_card() → OG 이미지 생성

Row Level Security:
- 유저는 자신의 점수만 쓸 수 있음
- 랭킹은 전체 읽기 가능
```

추후 자체 서버 교체 시 인터페이스 레이어로 분리해서 Supabase 의존성 최소화.

### 봇 시스템

Ghost Dash 방식 그대로:

- 봇 100개로 시작 (화면 노출에따라 조정 가능)
- 실유저 스코어가 쌓이면 봇을 점진적 제거
- 봇 난이도: 실제 유저 스코어 분포에 맞춰 설정 (초반엔 낮게)

## 수익화 전략

**구조: 무료 + IAP (유료 앱 금지)**

유료 앱은 신규 개발자 게임에서 다운로드 급감. 토스 미니앱은 유료 판매 불가.

### 광고 종류별 판단 기준

광고를 한 덩어리로 보면 안 됨. 종류마다 이탈 영향과 데이터 오염 수준이 다름.

| 광고 종류                  | 이탈 영향        | 데이터 오염 | 적용 시점         |
| -------------------------- | ---------------- | ----------- | ----------------- |
| **리워드 광고** (선택형)   | 거의 없음        | 낮음        | **출시부터**      |
| **전면 광고** (인터스티셜) | 있음 — 흐름 끊음 | 높음        | 게임 개선 완료 후 |

**리워드 광고를 처음부터 넣는 이유:**

- 유저가 선택하므로 강제 이탈 없음
- 데이터 오염이 적어 밸런스 패치 효과 측정에 방해 안 됨
- 수익이 적더라도 0보다 낫고, 폭발적 성장 시 바로 수익으로 연결됨

**전면 광고를 나중에 넣는 이유:**

- 게임 흐름을 끊어 이탈 가속 가능
- "리텐션이 낮은 게 게임 문제인지 광고 문제인지" 구분 안 됨 → 개선 측정 불가
- 밸런스 패치가 완료돼 더 이상 게임을 개선하지 않겠다는 판단 이후에 켜기

**프로모션(마케팅비 집행)은 별개:**

- 광고 SDK(수익화)와 프로모션은 다른 개념
- 리텐션 낮을 때 낭비인 건 프로모션. 유저를 사와도 다 이탈하면 CPI 손해
- 광고 SDK는 유저가 오면 돈 받는 구조라 리텐션과 무관하게 항상 켜둬도 됨

### 단계별 수익화
