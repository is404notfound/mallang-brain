# 연습실·콘테스트·뇌 타워 밸런스 설계

결정일: 2026-09-13  
상태: 제품 방향 승인, 구현 전 상세 수치 검증 필요

이 문서는 나중에 브레인 연습실과 브레인 콘테스트를 만들 때 사용할 설계 기준이다. **스테이지별 짧은 연습과 3분 연습 코스를 모두 만든다.** 매 연주 뒤에는 게임 안의 연주 성향을 알려주고, 콘테스트 결과는 뇌 타워에서 보여준다.

여기에 적힌 기능은 Gate 0 범위가 아니다. [Gate 1의 콘테스트 재미 검증](product-vision-and-roadmap.md)을 먼저 통과한 뒤 순서대로 만든다.

## 1. 각 기능의 역할

| 기능 | 사용자가 얻는 재미 | 게임에서 맡는 역할 |
| --- | --- | --- |
| 스테이지별 연습 | 막힌 부분을 골라 짧게 고치는 재미 | 콘테스트에서 실패한 이유를 해결한다 |
| 오늘의 3분 연습 코스 | 무엇을 고를지 고민하지 않고 편하게 연주하는 재미 | 최근 약한 패턴을 이어서 연습한다 |
| 이번 연주의 뇌 | 매 판 다른 별명을 받는 재미 | 방금 연주의 특징을 쉽게 설명한다 |
| 나의 뇌 성향 | 나만의 연주 습관을 알아가는 재미 | 여러 판의 기록에서 비교적 꾸준한 특징을 찾는다 |
| 브레인 콘테스트 | 한 번에 어디까지 올라가는지 겨루는 재미 | 게임의 중심 도전이 된다 |
| 뇌 타워 | 내 실력과 다른 참가자의 분포를 한눈에 보는 재미 | 결과와 성장 기록을 눈에 보이게 만든다 |

핵심 흐름은 다음과 같다.

```text
콘테스트에서 Stage 7 실패
        ↓
추천 연습: Stage 7 좌우 엇갈림
        ↓
30~45초 스테이지 연습 또는 3분 연습 코스
        ↓
이번 연주의 뇌 성향과 한 줄 조언
        ↓
콘테스트 다시 도전
        ↓
뇌 타워에서 이전 기록과 높이 비교
```

연습실의 성공은 오래 머무는 것만으로 판단하지 않는다. **연습 뒤 콘테스트로 돌아가 이전보다 나아지는가**를 함께 본다.

## 2. 검토한 세 가지 연습실 구조

| 방법 | 문제를 푸는 힘 | 다른 기능에 미치는 영향 | 혼자 관리하기 | 기존 RhythmCore와 맞는가 |
| --- | --- | --- | --- | --- |
| 3분 코스만 제공 | 선택이 간단하지만 특정 스테이지를 다시 익히기 어렵다 | 작음 | 쉬움 | 잘 맞음 |
| 스테이지 목록만 제공 | 막힌 곳을 바로 고를 수 있지만 목록이 길고 연습이 너무 짧아질 수 있다 | 중간 | 스테이지 설명·해금 관리가 필요 | 같은 스테이지 데이터를 쓰면 맞음 |
| **추천 연습 + 스테이지 목록 + 3분 코스** | 빠른 교정과 편한 연주를 모두 제공한다 | 중간 | 공통 패턴과 결과 계산을 함께 쓰면 관리 가능 | **가장 잘 맞음** |

세 번째 방법을 선택한다. 별도 리듬게임을 두 개 만들지 않는다. 콘테스트의 노트, 판정, 패턴 이름을 연습실에서도 그대로 사용한다.

## 3. 스테이지별 짧은 연습

### 화면과 해금

연습실 첫 화면 맨 위에는 최근 콘테스트 결과로 고른 추천 연습 하나를 둔다. 그 아래에는 스테이지 목록을 둔다.

```text
오늘의 추천 연습
Stage 7 · 좌우 엇갈림
[바로 연습]

스테이지 연습
Stage 1 · 정박자 입문       A
Stage 2 · 좌우 번갈아 치기  B+
Stage 3 · 빠른 두 번 치기   미연습
...
Stage 7 · 좌우 엇갈림       추천
Stage 8 · 아직 도달하지 않음
```

- Stage 1은 처음부터 열린다.
- 콘테스트에서 도달한 스테이지까지 연다. 실패한 스테이지도 즉시 연다.
- 아직 도달하지 않은 스테이지는 이름과 잠금 조건만 보여준다. 자세한 패턴은 미리 보여주지 않는다.
- 추천 기본값은 최근 콘테스트에서 실패한 스테이지다.
- 최근 실패 기록이 없으면 아직 연습하지 않은 가장 낮은 스테이지를 추천한다.
- 사용자는 추천을 따르지 않고 열린 스테이지를 직접 고를 수 있다.

### 한 번의 길이

콘테스트의 한 스테이지는 4마디라서 그대로 연습하면 너무 짧다. 짧은 연습에서는 같은 기술을 세 번 연주한다.

1. 익히기: 원래 속도의 80%를 첫 기준으로 삼고 안내를 많이 보여준다.
2. 실전: 원래 속도와 원래 판정으로 연주한다.
3. 확인: 원래 속도로 연주하되 안내를 줄인다.

한 번의 목표 길이는 카운트인을 포함해 **30~45초**다. 80% 속도는 첫 시험값이며 실제 플레이에서 70~90% 사이로 조정할 수 있다. 세 번 모두 같은 기술 태그를 사용하고, 전혀 다른 패턴을 끼워 넣지 않는다.

실패와 중도 탈락은 없다. 숫자 점수는 마지막에만 보여주고, 연주 중에는 소리·말렛·건반·캐릭터 반응으로 알려준다.

## 4. 오늘의 3분 연습 코스

- 정확히 3분을 목표로 하며 카운트인과 짧은 전환도 포함한다.
- 같은 RhythmCore와 스테이지 패턴을 사용한다.
- 최근 기록에서 자주 놓친 기술을 우선해 3~5개 연습 블록을 고른다.
- 기록이 부족한 새 사용자는 Stage 1~3의 입문 코스를 받는다.
- 같은 기술만 3분 내내 반복하지 않는다. 가장 약한 기술의 비중은 전체의 절반을 넘기지 않는 것을 첫 기준으로 삼는다.
- 중간에 틀려도 멈추지 않는다. 일시정지에서 돌아오면 네 박자를 다시 센다.
- 하루 첫 3분 코스 완료에만 기존 학점 `+1`을 적용한다. 짧은 스테이지 반복은 학점을 계속 주지 않는다.

추천 코스는 사용자의 약점을 확정된 성격처럼 말하지 않는다. “최근 좌우 전환에서 놓친 음이 많았어요”처럼 관찰한 게임 기록만 설명한다.

## 5. 뇌 성향 평가

### 두 종류의 결과

| 결과 | 계산 범위 | 목적 |
| --- | --- | --- |
| 이번 연주의 뇌 | 방금 끝낸 한 판 | 매 판의 재미와 바로 쓸 조언 |
| 나의 뇌 성향 | 최근 유효 기록 여러 판 | 쉽게 흔들리지 않는 장기 연주 프로필 |

한 판의 판정 가능한 입력이 32개보다 적으면 성향을 확정하지 않고 `알아보는 중`으로 표시한다. 장기 성향은 **유효한 연주 5판과 판정 가능한 입력 160개**가 모두 모인 뒤 처음 보여주는 것을 시작값으로 삼는다. 이 수치는 실제 기록의 흔들림을 보고 조정한다.

한 판마다 주 성향 하나와 잘한 점 하나만 보여준다. 장기 성향은 주 성향 하나와 보조 성향 하나까지 보여준다. 한 번의 이상한 기록 때문에 장기 성향이 바로 바뀌지 않도록 최근 여러 판을 함께 계산한다.

### 성향 이름과 근거

| 이름 후보 | 사용하는 게임 기록 | 뜻 |
| --- | --- | --- |
| 정박뇌 | 입력 시점의 흔들림이 작다 | 일정한 박자를 잘 유지한다 |
| 앞서뇌 | 입력이 목표보다 이른 쪽에 계속 모인다 | 소리보다 손이 먼저 나가는 편이다 |
| 느긋뇌 | 입력이 목표보다 늦은 쪽에 계속 모인다 | 박자를 확인하고 따라가는 편이다 |
| 출렁뇌 | 이른 입력과 늦은 입력이 크게 섞인다 | 박자 간격이 흔들리는 편이다 |
| 엇박뇌 | 엇박·당김음 기술 태그에서 실수가 집중된다 | 엇갈린 리듬을 더 연습하면 좋다 |
| 한쪽뇌 | 왼손과 오른손의 정확도 차이가 크다 | 한쪽 말렛이 더 익숙하다 |
| 급발진뇌 | 판정 대상이 아닌 추가 입력이 많다 | 다음 음을 너무 빨리 준비하는 편이다 |
| 회복뇌 | Miss 뒤 두 음 안에 정확한 입력으로 돌아온다 | 실수 뒤 박자를 잘 되찾는다 |

이 이름은 현실의 성격, 지능, 집중력 또는 건강 상태를 뜻하지 않는다. 화면에는 `게임 안에서 나타난 연주 스타일`이라고 설명한다. 놀리는 느낌이 강한 이름은 사용자 관찰 뒤 바꾼다.

정확한 판정 수치는 Gate 1 기록을 보고 별도 표로 확정한다. 모든 사용자가 한 성향으로 몰리면 사용자를 탓하지 않고 다음 순서로 확인한다.

1. 성향 계산 기준이 너무 넓거나 좁은가?
2. 특정 기기의 오디오·터치 지연이 섞였는가?
3. 해당 스테이지가 한 종류의 실수만 지나치게 만들고 있는가?
4. 이름이 실제 기록을 정확하게 설명하는가?

성향은 추천 연습에만 연결한다. 점수, 판정창, 콘테스트 입장, 공식 순위에서 이득이나 불이익을 주지 않는다.

## 6. 콘테스트 난이도

콘테스트는 한 번 시작하면 실패하거나 20개 스테이지를 마칠 때까지 이어진다. 난이도는 속도만 올리지 않는다.

| 구간 | 중심 기술 | 밸런스 목표 |
| --- | --- | --- |
| Stage 1~3 | 기본 박자와 입력 이해 | 처음 하는 사람도 규칙을 배운다 |
| Stage 4~6 | 좌우 전환과 홀드 입문 | 손을 바꾸는 판단을 익힌다 |
| Stage 7~9 | 엇박 입문 | 익숙한 박자에서 한 단계 벗어난다 |
| Stage 10~12 | 홀드와 짧은 음의 혼합 | 두 종류의 입력을 함께 처리한다 |
| Stage 13~16 | 빠른 판단과 복합 전환 | 숙련자의 차이가 나타난다 |
| Stage 17~20 | 종합 실기 | 지금까지 배운 기술을 함께 사용한다 |

각 스테이지에서 크게 올리는 어려움은 한 가지를 기본으로 한다. 속도, 좌우 판단, 엇박, 홀드를 모두 한 번에 올리면 무엇 때문에 탈락했는지 알기 어렵다.

같은 날의 공식 참가자는 같은 chart, seed, ruleset으로 겨룬다. `ruleset`은 판정과 순위 규칙의 버전이다. 난이도나 통과선을 바꾸면 새 버전으로 나누고 이전 공식 기록과 섞지 않는다.

## 7. 뇌 타워와 명예의 전당

첫 버전의 뇌 타워는 **오늘의 공식 결과를 보여주는 20층 타워**다. 오래된 모든 버전의 기록을 섞은 영구 랭킹은 뒤로 미룬다.

- 한 층은 콘테스트의 한 스테이지다.
- 실패한 스테이지는 `도전 중인 층`, 마지막으로 통과한 스테이지는 `통과 층`으로 나눠 보여준다.
- 같은 층 안에서는 기존 공식 순위 규칙에 따라 위치를 정한다.
- 이번 기록과 오늘의 개인 최고 기록을 함께 표시한다.
- 완주자는 옥상의 `명예의 전당`에 놓는다.
- 사용자의 뇌는 크게 표시하고, 다른 참가자는 분포가 보일 정도로 작게 묶어 표현해 화면과 성능 부담을 줄인다.

결과 예시는 다음과 같다.

```text
이번 기록       Stage 7 도전
오늘 최고       Stage 8 도전
실제 참가자 중  상위 31%
다음 목표       Stage 7 통과까지 정확도 4%p
```

실제 참가자 기록이 20명 이상일 때만 실제 백분위를 표시한다. 20명 미만이면 연습생 기준의 `임시 순위대`라고 분명히 쓴다. 연습생을 실제 사람처럼 보이게 하지 않는다.

뇌 타워는 결과 화면에서 먼저 확인한다. 별도 방문 화면과 영구 명예의 전당은 사용자가 결과에서 타워를 자주 확인하는지 본 뒤 확장한다.

## 8. 밸런스를 판단할 기록

| 확인할 질문 | 볼 기록 | 문제가 있다는 신호 |
| --- | --- | --- |
| 특정 스테이지가 갑자기 어려운가? | 스테이지별 도착·통과·실패 원인 | 앞 단계와 비교해 탈락이 갑자기 몰림 |
| 짧은 연습이 실제로 도움이 되는가? | 연습 전후 같은 스테이지의 정확도와 통과 | 반복해도 다음 세 번의 콘테스트 결과가 나아지지 않음 |
| 추천이 맞는가? | 추천 시작률, 완료율, 직접 선택으로 변경한 비율 | 사용자가 추천을 자주 무시함 |
| 3분 코스가 편하게 쓰이는가? | 완료율, 중도 종료 위치, 다시 이용한 날 | 특정 블록에서 반복 이탈 |
| 연습실이 콘테스트를 대신하는가? | 연습 뒤 콘테스트 복귀율, 사용자당 콘테스트 시작 수 | 연습 사용자는 늘지만 콘테스트 시작이 줄어듦 |
| 성향 결과가 믿을 만한가? | 같은 사용자의 성향 변경 횟수, 이름별 분포 | 한 판마다 바뀌거나 한 이름에 대부분 몰림 |
| 타워가 다시 도전을 만드는가? | 결과 타워 확인 뒤 재도전, 다음 목표 확인 | 타워를 봐도 결과 화면에서 바로 나감 |

연습한 사람의 성적이 올랐다는 사실만으로 연습이 원인이라고 단정하지 않는다. 원래 게임을 많이 하는 사용자가 연습도 많이 할 수 있다. 같은 사용자의 연습 직전과 이후를 먼저 보고, 이후 충분한 사용자가 모이면 추천 방식 차이를 비교한다.

기존 제품 문서의 안전선도 유지한다. 초기 관찰 10명 중 4명 이상이 연습실만 사용하거나, 사용자당 콘테스트 시작 수가 기존보다 20% 이상 줄면 연습실의 홈 노출과 추천 흐름을 다시 검토한다.

## 9. 일부 기능이 실패할 때

| 실패 | 사용자에게 남길 기능 | 처리 원칙 |
| --- | --- | --- |
| 추천 계산 실패 | 스테이지 목록과 기본 3분 코스 | 가장 낮은 미연습 스테이지를 추천한다 |
| 성향 계산 자료 부족 | 정확도와 판정 분포 | `알아보는 중`으로 표시하고 임의의 별명을 만들지 않는다 |
| 성향 계산 오류 | 원래 연주 결과 | 성향 카드만 숨기고 학점·점수에 영향 주지 않는다 |
| 순위 서버 오류 | 연습실, 로컬 결과와 개인 최고 | 공식 백분위와 명예의 전당을 확인할 수 없다고 알린다 |
| 실제 참가자 부족 | 연습생 기준 임시 순위대 | 실제 사용자 분포처럼 표현하지 않는다 |
| 타워 화면 오류 | 숫자로 된 도달 스테이지와 결과 | 재도전 버튼과 결과 저장은 계속 작동한다 |

추천, 성향, 타워 어느 하나가 실패해도 리듬 연주와 로컬 결과까지 멈추지 않게 설계한다.

## 10. 기존 코드 방향과 맞추는 방법

- 콘테스트와 두 연습 방식은 하나의 `RhythmCore`를 공유한다.
- 스테이지 이름, 기술 태그, BPM, 노트 구간은 하나의 chart metadata에서 읽는다. 화면마다 같은 내용을 따로 적지 않는다.
- `StagePractice`는 선택한 스테이지 구간을 세 번 실행한다.
- `DailyPracticeCourse`는 같은 기술 태그를 사용해 3분 분량을 고른다.
- `BrainStyleEvaluator`는 판정 결과를 읽기만 한다. 판정 점수 자체를 바꾸지 않는다.
- `BrainTower`가 쓰는 공식 순위는 기존 rank tuple과 실제 사용자 최소 20명 규칙을 그대로 사용한다.
- 추천·성향 기준을 바꾸면 버전을 기록한다. 바뀐 결과를 예전 결과와 같은 기준인 것처럼 비교하지 않는다.

## 11. 구현 순서

1. Gate 1에서 콘테스트의 판정·스테이지·재도전 재미를 먼저 검증한다.
2. chart metadata에 스테이지 이름과 기술 태그를 붙인다.
3. 추천 카드와 스테이지별 30~45초 연습을 만든다.
4. 한 판의 뇌 성향과 자료 부족 처리를 만든다.
5. 같은 데이터를 재사용해 3분 추천 코스를 만든다.
6. 여러 판이 쌓였을 때 나의 뇌 성향을 만든다.
7. 공식 순위가 준비되면 결과 화면의 오늘 뇌 타워를 만든다.
8. 실제 행동을 확인한 뒤 별도 명예의 전당 화면을 만들지 결정한다.

구현 전에 성향별 정확한 수치, 스테이지별 기술 태그, 3분 코스 선택 규칙을 Gate 1 계획 안에서 확정한다. 현재 장비 측정이 남아 있는 Gate 0을 이 기능 때문에 통과로 처리하거나 기준을 바꾸지 않는다.
