## 어려운 말 빠르게 보기

| 말 | 뜻 |
| --- | --- |
| Gate 0 | 재미있는 기능을 만들기 전에, 두 플랫폼에서 기술이 되는지 확인하는 첫 시험 |
| Unity | 게임을 만드는 프로그램 |
| Apps in Toss | 토스 앱 안에서 작은 앱과 게임을 실행하는 공간 |
| WebGL | 웹에서 게임을 실행할 수 있게 만드는 방식 |
| `.ait` | Apps in Toss에서 실행할 수 있도록 만든 앱 묶음 파일 |
| `webBundleDir` | `.ait`로 묶을 웹 파일이 있는 폴더를 알려 주는 설정 |
| Build | 코드를 설치하거나 실행할 수 있는 파일로 만드는 일 |
| Test | 약속한 대로 작동하는지 확인하는 시험 |
