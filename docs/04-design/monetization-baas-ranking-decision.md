# 수익화·백엔드·랭킹 아키텍처 결정 (확정)

이 문서는 구현 중 확정한 제품 결정을 기록합니다. 잠긴 기획 패키지 밖에서 정한 내용이라, 다음 기획 갱신 때 패키지(`specs/001-listen-and-repeat-core`)로 올려 반영합니다.

## 개요

**수익화는 확정**입니다(캐릭터 × 악기 조합 상점, 인앱결제). 그래서 최종 아키텍처는 **백엔드(BaaS) 기반**으로 가고, 랭킹도 그때 **서버 기반으로 전환**합니다. 다만 **지금 프로토타입 단계에서는 서버를 만들지 않습니다** — 이음새만 깨끗하게 두고, 출시 단계에서 붙입니다.

## 결정 사항

- **결제(IAP)**: 결제 처리 자체는 애플/구글 스토어가 합니다(자체 결제 서버 불필요). 다만 **유료 상품 보호를 위해 영수증 검증과 소유권 저장이 필요**하므로, 출시 단계에서 백엔드가 들어갑니다.
- **백엔드는 BaaS로**: Firebase·PlayFab·Supabase 중 하나를 써서 **영수증 검증 + 소유권(구매 복원) + 온라인 랭킹**을 한 번에 처리합니다. 자체 서버를 처음부터 짓지 않습니다. (BaaS 후보는 출시 기획에서 확정합니다.)
- **랭킹**: 현재는 **기준표(벤치마크) 비교**입니다 — 공식 집계 없이 단계 기준으로 비교하며, 로컬 데이터(`Data/ranking-benchmark.json`)와 `RankingRules` 로직으로 동작합니다. 수익화 출시 때 **BaaS 리더보드로 전환**해 실제 온라인 랭킹으로 바꿉니다.
- **전환이 싼 이유**: 클라이언트에 이미 **제출 계약(`RankingSubmission`)과 가짜 서버(`FakeRankingServer`)**가 구현·검증돼 있습니다(로직 레인 L7). 출시 때 **가짜 서버만 BaaS 클라이언트로 교체**하면 랭킹이 온라인으로 바뀝니다.

## 랭킹 화면 재설계 — 리스트형(온라인 리더보드)으로 확정

- 2026-11-09 사용자 결정: 랭킹 화면을 **기준표/티어 표가 아니라 실제 랭킹 리스트**(1등·2등~10등·⋯·내 등수)로 바꿉니다. 제목·부제는 뺍니다. 상단에 내 티어(등급 메달·점수·도달)를 두고, 중앙에 리더보드 리스트를 핵심으로 둡니다.
- 이는 **온라인 랭킹(실제 플레이어 데이터)을 1차 디자인으로 확정**한다는 뜻입니다. 즉 BaaS 전환이 '있으면 좋은 것'이 아니라 **랭킹 화면이 성립하려면 필요한 것**이 됩니다(프로토타입은 기준표/티어로 대체 운영, 온라인 전환 시 리스트가 채워짐 — 스펙의 '주변 순위' 온라인 모드와 일치).
- **다음 기획 패키지(온라인/수익화)에 포함할 것**: 리더보드(순위·주변 순위·내 등수) UX와 서버 스키마(점수·순위·시즌), 오프라인(서버 전) 폴백은 기준표/티어.
- 패키지 밖 입력이므로 다음 기획 갱신 때 `specs/...`로 승격해 FR-021~024(랭킹)에 반영합니다.

## 단계(타이밍)

1. **프로토타입(지금)**: 서버 없이 — 기준표 랭킹(로컬) + 결제-준비된 클라이언트. 목표는 재미·손맛 검증입니다.
2. **출시 전(별도 흐름)**: 백엔드·IAP를 별도 기획/구현 흐름으로 엽니다 — BaaS 선택 → 영수증 검증 + 소유권 + 온라인 랭킹 전환. 이 작업은 game-build 프로토타입과 분리합니다.

## 주의사항

- 이 결정은 **프로토타입 빌드를 바꾸지 않습니다**. 지금 결과·랭킹 화면은 서버 없이 조립하고, 전환은 출시 단계에서 합니다.
- 랭킹 화면은 승인된 고해상 캔버스가 없어(타이틀·플레이·결과 3장만 확정), 와이어프레임(`specs/.../wireframes/ranking.html`)과 우리 스타일로 설계합니다. 고해상 랭킹 캔버스가 필요하면 에셋 요청으로 추가합니다.

## 용어 설명

- **IAP(인앱결제)**: 앱 안에서 스토어를 통해 상품을 사는 결제 방식입니다.
- **BaaS(백엔드 서비스)**: 서버를 직접 만들지 않고, 검증·저장·랭킹 같은 기능을 빌려 쓰는 외부 서비스입니다(Firebase 등).
- **영수증 검증**: 스토어가 준 구매 증서를 서버가 스토어에 다시 확인해 위조를 막는 절차입니다.
- **기준표(벤치마크)**: 다른 사람과 비교가 아니라, 미리 정한 등급표에 내 도달을 견주는 방식입니다.
