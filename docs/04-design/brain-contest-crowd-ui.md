# 브레인 콘테스트 군중 UI 설계

> 한 줄 방향: **체육관을 개조한 음악대학 제1대합주관에서, 100명의 말랑뇌가 실제로 줄어드는 생존 합주.**

이 문서는 브레인 콘테스트의 경기 화면과 군중 표현을 만들 때 사용할 기준이다. 참고 이미지의 캐릭터, 의상, 장소와 화면 구도를 그대로 따라 만들지 않는다. 여러 참가자가 같은 공간에 모여 있고, 참가자가 줄어드는 모습이 곧 진행 상황이 되는 원칙만 가져온다.

## 1. 장소는 제1대합주관

첫 콘테스트 장소는 오래된 교내 체육관을 음악대학 합주실로 바꾼 `제1대합주관`이다.

- 따뜻한 나무 바닥과 오래된 체육관 선을 남긴다.
- 벽에는 흡음판, 학교 문장, 학과 현수막과 전자 점수판을 단다.
- 접이식 관람석, 악기 보관 카트, 보면대, 양쪽 출입문을 둔다.
- 운동 기구는 두지 않는다. 이곳은 헬스장이 아니라 많은 학생이 함께 시험을 보는 학교 시설이다.
- 바닥의 선 일부는 오선지와 박자 칸처럼 보이게 바꾼다.

콘서트홀보다 이 장소가 좋은 이유는, 화려한 공연보다 **학교 실기시험에 참가했다는 느낌**을 더 빠르게 주기 때문이다. 나중에 고학년 무대로 콘서트홀을 열면 성장도 더 크게 느껴진다.

## 2. 가로 화면 구조

카메라는 플레이어 뒤쪽의 조금 높은 위치에서 합주관 전체를 내려다본다. 참가자는 플레이어를 감싸는 U자 대형으로 선다.

```text
┌────────────────────────────────────────────────────┐
│  1학년 마림바 실기      STAGE 07      남은 뇌 63  │
│ [접이식 관람석: 작게 보이는 참가자와 학교 현수막] │
│                                                    │
│       🧠  🧠  🧠  🧠  🧠  🧠  🧠               │
│    🧠  🧠  🧠  🧠  🧠  🧠  🧠  🧠            │
│                                                    │
│                 ●  ○  ●  ━  ○                    │
│                   나의 말랑뇌                      │
│  [왼쪽 입력]  ━━━━━ 마림바 건반 ━━━━━  [오른쪽 입력] │
└────────────────────────────────────────────────────┘
```

- 아래 25%는 마림바와 좌우 입력 영역이다.
- 가운데 50%는 자세히 움직이는 참가자와 리듬 표시 영역이다.
- 위 25%는 접이식 관람석, 현수막과 전자 점수판이다.
- 리듬 표시는 참가자 앞이 아니라 빈 중앙 통로 위에 둔다.
- 플레이어 주변에는 학교 대표색으로 얇은 바닥 원을 그려 내 위치를 바로 찾게 한다.

화면이 북적여도 노트, 마림바와 내 캐릭터가 가장 먼저 보여야 한다. 군중은 리듬 입력을 가리거나 판정 시간을 알려 주는 척하면 안 된다.

## 3. 100명을 보이는 방법

100명을 모두 같은 크기와 같은 움직임으로 그리면 화면이 작아지고 성능도 나빠진다. 다음 세 단계로 나눈다.

- 플레이어 1명
- 바닥에서 자세히 보이는 참가자 23명
- 뒤쪽 관람석과 가장자리에서 작게 보이는 참가자 76명

합계는 100명이다. 뒤쪽 참가자는 작은 캐릭터 여러 명을 한 묶음으로 그린다. 색, 모자, 악기와 움직이는 시작 시간만 바꿔 같은 그림을 반복해서 쓴다. 남은 인원이 24명 이하가 되면 생존자는 모두 자세한 캐릭터로 보여 준다.

화면 속 참가자 수와 전자 점수판의 숫자는 항상 같아야 한다. 성능 때문에 자세한 캐릭터 수를 줄여도, 작은 참가자 표시는 남겨 실제보다 적게 보이지 않게 한다.

## 4. 군중이 곧 진행 UI

항상 떠 있는 숫자와 막대만으로 진행을 설명하지 않는다. 짧은 스테이지가 끝날 때 교내 방송 종이 울리고, 탈락한 참가자의 보면대가 접힌다.

1. 마지막 판정 뒤 0.3초 동안 모두 자세를 멈춘다.
2. 전자 점수판이 `100 → 78`처럼 바뀐다.
3. 탈락한 말랑뇌가 납작해지거나 말렛을 떨어뜨린다.
4. 양쪽 출입문으로 우르르 빠져나간다.
5. 남은 참가자가 한 줄 앞으로 이동한다.
6. 다음 스테이지의 네 박자 세기가 시작된다.

전체 전환은 1.5초 안에 끝낸다. 같은 탈락 장면을 자주 봐도 지루하지 않도록 반응은 네 종류만 준비해 섞어 쓴다.

- 성적표를 들고 터덜터덜 나가기
- 말렛이 먼저 굴러가서 뒤따라가기
- 친구 둘이 서로 부축해 나가기
- 너무 진지하게 교수에게 인사하고 나가기

참가자가 줄어든 빈자리는 숨기지 않는다. 비어 있는 바닥과 접힌 보면대가 보여야 생존했다는 느낌이 강해진다.

## 5. 화면에 계속 보이는 정보

| 위치 | 정보 | 이유 |
| --- | --- | --- |
| 왼쪽 위 | 현재 스테이지와 실기 이름 | 지금 무엇을 연주하는지 알려 준다 |
| 가운데 위 | 짧은 리듬 표시 | 시선이 군중으로 흩어져도 입력을 놓치지 않게 한다 |
| 오른쪽 위 전자 점수판 | 남은 참가자 수 | 군중이 줄어든 결과를 숫자로 확인한다 |
| 플레이어 가까이 | 콤보와 이번 판정 | 내 연주 결과만 빠르게 확인한다 |

실시간 상위 퍼센트와 정확한 순위는 계속 띄우지 않는다. 연주 중에는 남은 참가자 수만 보여 주고, 정확한 분포와 순위는 결과의 뇌 타워에서 보여 준다. 그래야 입력 화면이 덜 복잡하고 결과 화면의 역할도 남는다.

## 6. 군중 반응 규칙

- `Perfect`에서는 가까운 참가자 두 줄이 박자에 맞춰 짧게 튄다.
- `Good`에서는 내 말랑뇌와 바로 옆 참가자만 작게 반응한다.
- `Miss`에서는 내 주변 한 칸만 움찔한다. 화면 전체를 흔들지 않는다.
- 큰 반응은 스테이지 통과와 탈락 때만 사용한다.
- 한순간에 크게 움직이는 군중 구역은 두 곳을 넘지 않는다.
- 군중의 소리는 작게 두고, 플레이어의 마림바 소리는 항상 선명하게 남긴다.

군중 반응은 판정 결과를 읽기만 한다. 군중 수, 표정과 효과가 리듬 판정이나 점수를 바꾸면 안 된다.

## 7. 적은 에셋으로 만드는 범위

첫 버전에서는 다음만 만든다.

- 합주관 배경 1개
- 학교 점수판, 현수막, 출입문, 보면대, 악기 카트
- 말랑뇌 기본 몸 1종과 몸 모양 변형 5종
- 학교 대표색을 포함한 색 조합 8종
- 모자와 타악기 소품 8종
- 연주, 환호, 실수, 탈락의 짧은 동작 각 2종
- 가까운 참가자용 자세한 그림과 먼 참가자용 작은 그림

100개의 독립 캐릭터를 만들지 않는다. 몸, 색, 소품과 동작을 섞어 100개의 조합을 만든다. 수집 기능을 위한 의상 제작으로 범위를 넓히지 않는다.

## 8. 성능과 실패 처리

- 가까운 23명만 자주 움직인다. 먼 76명은 구역별로 묶어서 움직인다.
- 낮은 성능 설정에서는 가까운 참가자를 11명까지 줄이고, 나머지는 작은 군중 묶음으로 바꾼다.
- 탈락 효과와 종이 조각에는 동시에 보이는 최대 개수를 둔다.
- 군중 애니메이션을 불러오지 못하면 정지 캐릭터와 남은 인원 숫자를 보여 준다.
- 전자 점수판 연출이 실패하면 화면 오른쪽 위의 기본 숫자 UI로 바꾼다.
- 순위 서버가 실패해도 로컬 참가자 연출, 리듬 연주와 재도전은 계속된다.
- 군중 화면이 실패해도 `RhythmCore`의 판정, 점수와 스테이지 진행은 멈추지 않는다.

기기 성능 시험은 자동 시험과 실제 기기 측정을 나눠 진행한다. 다른 장비에서 아직 재지 않은 값은 통과로 기록하지 않는다. 기존 Gate 기준과 기간도 낮추지 않는다.

## 9. 검토한 장소 세 가지

| 장소 | 좋은 점 | 문제 | 판단 |
| --- | --- | --- | --- |
| 정식 콘서트홀 | 음악대학 느낌이 강하고 멋있다 | 1학년 첫 시험보다 졸업 공연처럼 보인다 | 고학년 장소로 남긴다 |
| 야외 캠퍼스 축제 | 밝고 군중을 많이 보여 주기 쉽다 | 오프닝과 느낌이 겹치고 시험의 긴장이 약하다 | 특별 행사로 남긴다 |
| 체육관을 개조한 제1대합주관 | 학교, 군중, 실기시험을 한 화면에 담는다 | 소품을 잘못 쓰면 일반 스포츠 게임처럼 보인다 | **첫 장소로 선택** |

제1대합주관은 기존 마림바 게임과 가장 잘 이어진다. 새 게임 규칙을 만들지 않고 표현만 바꾸므로 영향 범위가 작다. 같은 기본 캐릭터와 군중 묶음을 계속 쓸 수 있어 고치기도 쉽다.

## 10. 제작 순서와 확인 기준

1. 회색 도형으로 플레이어 1명, 가까운 참가자 23명, 먼 참가자 76명을 배치한다.
2. 마림바, 리듬 표시와 참가자가 서로 가리지 않는지 확인한다.
3. `100 → 78` 한 번의 탈락 장면을 만든다.
4. 남은 참가자가 앞으로 이동하고 다음 네 박자로 이어지게 한다.
5. 낮은 성능 설정과 군중 애니메이션 실패 화면을 만든다.
6. 마지막에 학교 현수막, 악기 카트, 표정과 소품을 더한다.

첫 사용자 시험에서는 다음을 확인한다.

- 10명 중 7명 이상이 3초 안에 `학교에서 여러 명이 함께 치르는 음악 실기시험`이라고 이해한다.
- 10명 중 9명 이상이 2초 안에 내 캐릭터와 리듬 표시를 찾는다.
- 10명 중 7명 이상이 한 스테이지 뒤 참가자가 크게 줄었다는 것을 숫자를 읽지 않고도 알아챈다.
- 군중을 켠 상태에서도 기존 성능 기준을 통과해야 한다. 실제 기기 측정 전에는 통과로 적지 않는다.

기준에 못 미치면 캐릭터를 더 만들지 않는다. 먼저 카메라 높이, 마림바 크기, 빈 중앙 통로와 점수판 위치를 고친다.
